# CS336(2025)
正如课程标题“Language Modeling from Scratch”所言，这门课会手把手带你从零构建大语言模型，并掌握诸多前沿主流的算法。与CS224N(2025)的proj(build gpt2)不同，没有丰富的脚手架，只有点到为止的提示，但是可以帮助你深刻地了解模型的细节。很有幸能在大二的时候，AI日新月异的今天接触这门课。这个仓库包含了本人对作业pdf的翻译(基于ChatGPT，由于幻觉可能存误)和作业的代码和笔记，希望对大家学习能有所帮助。
## Overview
- **Basic**

    第一份作业便是手搓GPT了。需要对transformer架构有所了解，实在无从下手可以先学习CS224N，或完成它的final project，对大模型的架构有初步的了解。这份作业从BPE分词器，到transformer block，再到adam optimizer都需要你从零写起。除此之外，你还可以学习到完整的模型训练过程，从加载数据集，到训练模型，保存checkpoint，参数调整等等。总而言之，单单写完第一个作业就能让你收获颇丰。
